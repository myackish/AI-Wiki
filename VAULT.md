# VAULT — канон волта

Волт `C:\myAI\` — общая память владельца и ИИ-агентов. Файлы — единственный источник правды. Это карта, не территория: ядро короткое, детали — в вики-страницах.

## Правила для агента

1. В начале содержательной задачи прочитай `index.md` (карта) и последние записи `log.md`. Дальше загружай только то, что нужно задаче, — не тащи всё сразу.
2. `log.md` — хроника, append-only: одна строка на событие, формат `[ГГГГ-ММ-ДД] тип | суть`, новые записи — в конец файла. Задним числом не редактировать; старое раз в год уезжает в `archive\log-<год>.md`.
3. Страницы в `wiki\` — «что верно сейчас»: обновляй и дедуплицируй, а не копи версии. Связывай страницы markdown-ссылками друг на друга.
4. `inbox\` — новое на разбор (агент разбирает по запросу владельца), `raw\` — исходники, неизменяемые (читать можно, править нельзя), `archive\` — холодное хранилище.
5. Секреты (пароли, ключи, токены) в волт не писать никогда — ни в файлы, ни в log.
6. После значимой работы: запись в `log.md`, обновить затронутые вики-страницы, внести новые страницы в `index.md`.
7. «Ревизия волта» — ритуал по запросу владельца: дедупликация, поиск противоречий и страниц-сирот, перенос важного из `log.md` в вики.
8. Служебная авто-память агента — отдельная вещь; волт — видимая и редактируемая владельцем база знаний. При противоречии волт главнее.

## Шимы (точки входа агентов)

- ZCode: `~/.zcode/AGENTS.md` → этот файл
- Claude Code: `CLAUDE.md`, Codex: `AGENTS.md` воркспейса — по той же схеме
