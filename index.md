# Карта волта

Обновляется агентом при каждом изменении структуры.

## Корень

- `VAULT.md` — канон: правила работы агента с волтом
- `SOUL.md` — характер и тон агента
- `about-me.md` — кто владелец
- `log.md` — хроника событий (append-only)
- `.gitignore` — служебное: исключения для git

## Папки

- `wiki\` — знания: страницы по темам (проекты, люди, решения, инструкции)
- `inbox\` — новое на разбор
- `raw\` — исходники, неизменяемые
- `archive\` — архивы (старые логи, закрытые страницы)
