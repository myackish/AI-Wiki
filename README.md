# AI Wiki — контекст-волт для ИИ-агента

Шаблон личной базы знаний в виде папки markdown-файлов, которую ведёт ИИ-агент (ZCode, Claude Code, Codex — любой, кто умеет читать и писать файлы). Файлы — единственный источник правды: человекочитаемо, ищется любым поиском, версионируется git, живёт десятилетиями.

## Идея

Обычно агент собирает знания о вас заново в каждом разговоре — и ничего не накапливается. Здесь между вами и агентом лежит «волт»: папка с ядром правил, хроникой и вики-страницами. Агент читает ядро в начале сессии, работает и сам поддерживает порядок — пишет хронику, обновляет страницы, ставит ссылки.

Два вида памяти, и их важно не смешивать:

- **Хроника** (`log.md`) — «что произошло»: только добавление, никогда не редактируется задним числом.
- **Знание** (`wiki/`) — «что верно сейчас»: обновляется и дедуплицируется, а не копится.

Без еженедельной ревизии любая вики гибнет — см. «Ритуалы» ниже.

## Структура

```text
myAI/
├── VAULT.md      ← канон: правила работы агента с волтом
├── SOUL.md       ← характер и тон агента
├── about-me.md   ← кто владелец
├── index.md      ← карта волта
├── log.md        ← хроника (append-only)
├── wiki/         ← знания: проекты, люди, решения, инструкции
├── inbox/        ← новое на разбор
├── raw/          ← исходники, неизменяемые
└── archive/      ← старые логи и закрытые страницы
```

## Установка (5 минут)

1. Скопируйте файлы шаблона в папку `C:\myAI\` (или любую свою) — сохраните структуру папок.
2. Заполните `about-me.md`.
3. Подключите агента — создайте файл-шим, который укажет ему на волт:
   - **ZCode**: `~/.zcode/AGENTS.md` (глобальный, действует во всех воркспейсах)
   - **Claude Code**: `CLAUDE.md`
   - **Codex**: `AGENTS.md` воркспейса

   Содержимое шима: «При первой содержательной задаче сессии прочитай `C:\myAI\index.md` и следуй правилам `C:\myAI\VAULT.md`. После значимой работы добавь запись в `C:\myAI\log.md` и обнови затронутые вики-страницы.»
4. Создайте **приватный** git-репозиторий и отправьте туда файлы — это бэкап и история изменений сразу.
5. Положите первый материал в `inbox/` и попросите агента его разобрать: он создаст страницу в `wiki/`, обновит `index.md` и сделает запись в `log.md`.

## Ритуалы

- **После значимой работы**: агент добавляет строку в `log.md` (формат `[ГГГГ-ММ-ДД] тип | суть`) и обновляет затронутые вики-страницы.
- **Раз в неделю — ревизия**: попросите агента «провести ревизию волта» — дедупликация, поиск противоречий и страниц-сирот, перенос важного из хроники в вики. Без этого ритуала любая вики гибнет.
- **Никогда**: не хранить в волте пароли, ключи и токены; не редактировать `log.md` задним числом; не менять файлы в `raw/`.
